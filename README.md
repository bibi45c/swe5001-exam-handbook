## 怎么用

1. **先学**：读复习书第 1–13 章，做每章末尾的小测验，再点开参考答案对照。
2. **再练**：做三套样卷，用复习书第 14–17 章逐题对答案；PAST 可以直接对照官方答案。
3. **考场查**：答题手册按题型组织。先从题干的指令词认出题型（T1–T17），再套卡上的答题骨架和句式，最后去案例附录找数字和用例。
4. **模拟**：两套模拟卷限时做完再看合订本里的答案。

打印建议：黑白、双面、A4。
